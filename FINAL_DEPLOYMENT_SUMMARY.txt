��� 常见问题快速解答

Q: 需要多长时间完成验证？
A: 首次验证30-45分钟（包括Docker构建），后续只需2-5分钟

Q: 需要什么环境？
A: Docker 20.10+, Docker Compose 2.0+, 10GB磁盘空间

Q: 脚本权限不足怎么办？
A: chmod +x local-deploy-test.sh troubleshoot.sh verify-deployment.sh

Q: Docker守护进程未运行？
A: macOS: brew services restart docker
   Linux: sudo systemctl restart docker
   Windows: 重启 Docker Desktop

Q: 端口被占用怎么办？
A: bash troubleshoot.sh 选择选项3查看端口，或使用 lsof -i :PORT

Q: 验证失败怎么办？
A: 运行 bash troubleshoot.sh 进行诊断，工具会提示修复方案

Q: 可以在CI/CD中使用吗？
A: 可以，使用 bash verify-deployment.sh 生成HTML报告

Q: 如何重新部署测试？
A: bash troubleshoot.sh → 选择9 → 选择3（删除数据），然后重新运行
