查看服务状态:
  docker compose ps

查看实时日志:
  docker compose logs -f

停止所有服务:
  docker compose down

重启脚本:
  bash docker-run.sh

问题排除
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Docker daemon is not running"
→ 启动 Docker Desktop，等待 30-60 秒

❌ "bind: address already in use"
→ 关闭占用端口的应用，或修改 docker-compose.override.yml

❌ 容器启动失败
→ 查看日志: docker compose logs container_name

❌ 应用加载缓慢
→ 正常！首次运行需要 3-10 分钟
