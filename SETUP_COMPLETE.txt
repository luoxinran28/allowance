⚡ 常用命令速查
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

查看服务状态:
  docker compose ps

查看实时日志（所有服务）:
  docker compose logs -f

查看特定服务日志:
  docker compose logs -f server      # 后端
  docker compose logs -f client      # 前端
  docker compose logs -f postgres    # 数据库

停止所有服务:
  docker compose down

重启所有服务:
  docker compose restart

重新启动完整脚本:
  bash docker-run.sh

清理所有数据后重启:
  docker compose down -v && bash docker-run.sh

⚠️  常见问题解答
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: 脚本显示 "Docker daemon is not running"
A: 启动 Docker Desktop，等待 30-60 秒，再次运行脚本

Q: 容器启动很慢
A: 正常！首次运行需要下载镜像和编译代码，总耗时 3-10 分钟

Q: 如何查看数据库中的数据
A: docker compose exec postgres psql -U postgres -d allowance

Q: 修改代码后没有看到改动
A: 查看日志看是否有编译错误：docker compose logs -f server

Q: 想要完全重置（删除所有数据）
A: docker compose down -v && bash docker-run.sh
